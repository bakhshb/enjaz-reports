# Digital-experience model

Use this reference only after the user chooses **التقرير الموحد مع نضج التجربة الرقمية**. The added slide follows the transactions summary and precedes the detail divider. The current model remains separate.

The current digital-maturity PDF is a required fourth input. Read and visually review **page one**, which contains the four perspective percentages, one sector row per agency/center, and the challenges table. The rest of the PDF provides context but has no destination in this approved one-slide section. Never carry the sample percentages, sector values, or challenge prose from the PowerPoint master into a generated report.

Run `scripts/digital_maturity.py` to extract a JSON review file. Its keys are `source_pdf_sha256`, `source_date_hijri`, `metrics` (`experience`, `satisfaction`, `complaints`, `tools`), `sectors` (name, four metrics, optional note), `challenges` (perspective and text), and `reviewed`. The extractor begins with `reviewed: false` because Arabic PDF text can reverse glyphs or ligatures. Compare the rendered PDF page with every field, correct the JSON, then set it to `true`. If a percentage, color-to-perspective association, sector name, note, or challenge is illegible or ambiguous, stop and request a clearer source. Do not infer it from the master examples.

The four perspective values and sector percentages are independent rates, not portions that must sum to 100. Preserve every number as shown. A missing perspective for one sector stays blank. A sector marked `قيد الدراسة` has a labeled gray bar and no invented percentages. Keep the challenge wording and perspective in source order. The approved slide has room for up to five sector rows and four challenge rows; if a future source exceeds that space, stop for a revised layout rather than silently drop records or shrink the 11 pt table font.

Reconcile the generated PPTX with the reviewed JSON and its source PDF hash. Inspect the native chart caches, embedded data, percentage labels, progress fills, note bars, and challenge text. Render the final slide in PowerPoint and compare it with the PDF and the unchanged master design. Correct any clipping, RTL reversal, stale sample value, overlap, or footer collision before delivery.
