# Minister summary message (رسالة ملخص التقرير لمعالي الوزير)

After the final report is delivered, reply with one Arabic summary message addressed to the Minister, inside a single fenced code block (```` ```text ````) so the user can copy it. Write nothing inside the block except the message.

## Source and model

- Build the message only from the **summary slides of the report that was actually delivered** (ملخص المهام، ملخص مشاريع سهيل، ملخص المعاملات، and for `digital` the digital-maturity summary and detail slides). These carry the same values as the validated Excel/PDF inputs; never add facts, numbers, dates, names or judgements that are not in the delivered report.
- The section set follows the delivered report's model automatically. Do not ask the user again:
  - `digital`: five sections — أولا المهام، ثانيا مشاريع سهيل، ثالثا المعاملات، رابعا مؤشر نضج التجربة الرقمية، خامسا طلبات الدعم المرفوعة لمعاليكم.
  - `standard`: four sections — the digital section is removed, طلبات الدعم becomes «رابعا»، and the introduction does not mention مؤشر نضج التجربة الرقمية.
- The date in the introduction is the report's own date (the date in the output name / cover), written as `D شهر YYYYم` with the Gregorian month name.
- If the report is rebuilt after an edit, regenerate the message from the new report.

## Writing rules

- Keep the fixed salutation, introduction, section headings, closing and blank-line spacing exactly as in the model below. Keep its formal register and sentence patterns («بلغ إجمالي…، منها…»، «المهمة:»، «المستجد:»، «أبرز المستجدات:»، «أبرز التحديات:»).
- Use correct Arabic number–noun agreement: مهمة واحدة / مهمتان / 3–10 مهام / 11+ مهمة; مشروع واحد / مشروعان / 3–10 مشاريع / 11+ مشروعا; معاملة واحدة / معاملتان / 3–10 معاملات / 11+ معاملة (e.g. «708 معاملات»، «402 معاملة»).
- Counts sentence: state the total, then every non-zero status (مكتملة، على المخطط، متأخرة، معلقة، لم تبدأ…). Close with «ولا توجد … متأخرة أو معلقة» (tasks), «ولا توجد مشاريع متأخرة أو لم تبدأ» (Suhail), «ولا توجد معاملات متأخرة» (transactions) only for statuses whose count is zero; drop the clause when none is zero.
- **أولا: المهام** — list every row of the report's `المهام المكتملة` table in order: numbered sector heading, then «المهمة:» and «المستجد:» from its task text and notes. Edit only for grammar and brevity; keep the meaning. If the report has delayed or suspended tasks, add «المهام المتأخرة:» / «المهام المعلقة:» blocks in the same format after the completed ones. If a table is empty, omit its block.
- **ثانيا: مشاريع سهيل** — one bullet per row of `أبرز التحديثات`, in order: «- <اسم المشروع>: <التحديث مختصرا>». Keep dates, percentages and target dates. Add «المشاريع المتأخرة:» and «التحديات:» bullets when those tables have rows.
- **ثالثا: المعاملات** — the counts sentence only.
- **رابعا: مؤشر نضج التجربة الرقمية** (`digital` only) — an opening sentence on the overall trend across the four perspectives versus the previous report when the report states it, then the fixed disclaimer paragraph, then one numbered block per perspective with its overall percentage: per-sector percentages, key progress items, and «أبرز التحديات». Use only percentages and challenges shown in the report.
- **طلبات الدعم المرفوعة لمعاليكم** — summarise each row of the report's `طلبات الدعم` table. When the table is empty, write «لم يتضمن التقرير طلبات دعم مستقلة مرفوعة لمعاليكم»، and only for `digital` may you add the needs that the report's challenges explicitly raise, as in the model.
- Plain text only: no Markdown bold, no emoji, no tables. Use «-» for bullets and «1.» for numbered blocks.

## Model message (digital report dated 5 November 2026)

This is the approved style reference. Its values are from that week only; never reuse them.

```text
معالي الوزير حفظه الله

السلام عليكم ورحمة الله وبركاته،

تجدون أدناه ملخص حالة المهام ومشاريع سهيل والمعاملات، بالإضافة إلى مستجدات مؤشر نضج التجربة الرقمية، وفق تقرير الإنجاز الأسبوعي المحدث بتاريخ 5 نوفمبر 2026م.

أولا: المهام

بلغ إجمالي المهام 22 مهمة، منها مهمتان مكتملتان و20 مهمة على المخطط، ولا توجد مهام متأخرة أو معلقة ضمن جدول متابعة المهام.

المهام المكتملة:

1. وكالة التحول الرقمي وتقنية المعلومات

المهمة: التنسيق مع وكالة التعاون الدولي لمتابعة وتنظيم زيارات كبار الشخصيات والوفود الرسمية خلال مؤتمر ومعرض الحج 2026، وإعداد الترتيبات اللازمة لاستقبالهم في جناح وكالة التحول الرقمي وتقنية المعلومات.

المستجد: تم التنسيق مع وكالة التعاون الدولي بشأن الترتيبات المطلوبة.

2. وكالة التعاون الدولي والشراكات

المهمة: عقد اجتماع مع وكيل وزارة الخارجية للشؤون القنصلية لمناقشة تحديات إعادة تفعيل التأشيرة الإلكترونية لمقيمي دول الخليج، وبحث سبل معالجتها.

المستجد: تم التواصل مع وكيل وزارة الخارجية للشؤون القنصلية، والاتفاق على دراسة الموضوع من قبل الفرق المختصة ومتابعته، وموافاة الوزارة بالمستجدات.

ثانيا: مشاريع سهيل

بلغ إجمالي مشاريع سهيل 19 مشروعا، منها 6 مشاريع مكتملة و13 مشروعا على المخطط، ولا توجد مشاريع متأخرة أو لم تبدأ.

أبرز المستجدات:

- دراسة تحسين نموذج عمل آلية تنظيم قدوم حجاج الخليج: اكتمل المشروع، وتم إدراج نموذج آلية تنظيم قدوم حجاج دول الخليج لموسم حج 1449هـ ضمن الموضوعات المقرر مناقشتها في مؤتمر ومعرض الحج.

- ضيف بلا حقيبة: تم استعراض خصائص المنصة في عرض تجريبي على المطارات القابضة بتاريخ 3 نوفمبر للمواءمة، وتعميم اتفاقية مستوى الخدمة على شركات تقديم الخدمة ومزودي الخدمة، إلى جانب الإعداد لجلسة حوارية وورشة عمل تفصيلية ضمن مؤتمر الحج.

- نسك امتثال مراكز الضيافة: تم استكمال التقييم الفني والمالي للعروض وإحالة النتائج إلى وكالة الخدمات المشتركة لاستكمال إجراءات الترسية. كما تمت مناقشة المستجدات في اجتماع اللجنة الإشرافية بتاريخ 2 نوفمبر، وعقد اجتماع لاستعراض المقر البديل للمشروع في مبنى 8.

- برنامج تأهيل المسؤولين في مكاتب شؤون الحج: تم استكمال إعداد المحتوى والحقائب التدريبية وتجهيز فنادق التدريب والقاعات، على أن يبدأ تدريب البعثات يوم الجمعة الموافق 6 نوفمبر 2026م.

- رحلة الحاج المتكاملة لموسم حج 1448هـ: تم الانتهاء من إعداد محتوى الورش التعريفية والتأهيلية، وجار العمل على دليل ولوحة مؤشرات متابعة تفاصيل رحلة الحاج المتكاملة، ويستهدف الانتهاء منهما بتاريخ 12 نوفمبر.

- دراسة إمكانية تسكين الحجاج بمكة المكرمة خلال أيام التشريق: تم إعداد سيناريوهات الاستفادة من المساحات ومراجعتها من مركز التخطيط الاستراتيجي وإبداء الملاحظات، وجار استيفاؤها.

- تطوير نموذج شركات حجاج الداخل: تم اعتماد بنود النموذج التشغيلي، وجار إعداد خطة تنفيذها، ويستهدف الانتهاء منها بتاريخ 12 نوفمبر.

- تطوير تجربة مظلات مبتكرة لضيوف الرحمن: اكتمل تجهيز منطقة «جربني» واستلام النماذج الابتكارية وإعداد آلية التجربة مع الزوار، مع استمرار التنسيق لتصميم نموذج هوية معتمد تمهيدا لتعميمه.

ثالثا: المعاملات

بلغ إجمالي المعاملات 708 معاملات، منها 402 معاملة مكتملة و306 معاملات على المخطط، ولا توجد معاملات متأخرة.

رابعا: مؤشر نضج التجربة الرقمية

تتواصل أعمال رفع مؤشر نضج التجربة الرقمية عبر أربعة مناظير رئيسية، مع ارتفاع الإنجاز في تجربة المستخدم والتعامل مع الشكاوى والتقنيات والأدوات، فيما بقي رضا المستفيد عند مستواه السابق.

وتعكس النسب أدناه تقدم استكمال المتطلبات والأدلة، بما يشمل الجاهزية وتحديد تواريخ التنفيذ والأعمال المنجزة، ولا تمثل نتيجة التقييم النهائي.

1. منظور تجربة المستخدم – نسبة الإنجاز 54%

- بلغت نسبة الإنجاز لدى وكالة التحول الرقمي وتقنية المعلومات 51%، ولدى مركز منصة نسك الرقمية 65%، فيما بقيت لدى وكالة شؤون الحج عند 15%.
- يتوقع ارتفاع إنجاز أربعة متطلبات تقنية إلى 80% بعد اعتماد دمج المحتوى في منصة نسك والحل الانتقالي للنطاقات الفرعية. كما تستمر تحسينات الموقع والتطبيق بانتظار إتاحة بيئة الاختبار، مع بلوغ إنجاز معالجة ملاحظات إمكانية الوصول في منصة نسك 85%.
- أبرز التحديات: اعتماد حلول دمج المحتوى والنطاقات، وتحديد مالك موحد للمحتوى، وتأخر تجاوب فريق وكالة شؤون الحج رغم ثلاث محاولات متابعة، آخرها بتاريخ 4 نوفمبر.

2. منظور رضا المستفيد – نسبة الإنجاز 15%

- بلغت نسبة الإنجاز لدى مركز منصة نسك الرقمية 15%، مع تقدم نشر استبانة «قيم تجربتك الرقمية» إلى 40%، وأعمال إشراك المستفيدين وقياس تلبية تطلعاتهم إلى 20%.
- تتواصل أعمال تحسين سرعة التصفح والأداء وخفض الأخطاء، فيما لم يكتمل دليل قياس إشراك المستفيدين، ولا تزال متطلبات نسك مسار عند 10%.
- أبرز التحديات: توحيد ملكية المحتوى، واستكمال أدلة القياس، وإنجاز التطويرات التقنية المرتبطة بالأداء والدعم.

3. منظور التعامل مع الشكاوى – نسبة الإنجاز 52%

- بلغت نسبة الإنجاز لدى وكالة تطوير الأعمال وخدمة المستفيدين 57%، ولدى وكالة التحول الرقمي وتقنية المعلومات 65%، ولدى مركز منصة نسك الرقمية 43%، ولدى وكالة شؤون الحج 34%.
- اكتمل متطلب متوسط زمن حل الشكوى، ونشر دليل الشروط والأحكام في منصة وتطبيق نسك. كما بلغ تقدم نشر قنوات استقبال الشكاوى فيهما 95%، مع بقاء إضافة أسماء الحسابات.
- أبرز التحديات: عدم اعتماد شواهد وكالة تطوير الأعمال حتى الآن، وتأخر خمسة متطلبات لديها، وعدم وجود مستجدات بشأن كراسة مركز الاتصال. كما لا يوجد ربط آلي لنقل شكاوى التواصل الاجتماعي إلى نظام إدارة علاقات العملاء، ويرتبط نشر دليل استقبال الشكاوى بتحديث الدليل والاتفاقيات.

4. منظور التقنيات والأدوات – نسبة الإنجاز 46%

- بلغت نسبة الإنجاز لدى مركز منصة نسك الرقمية 75%، وارتفعت لدى وكالة التحول الرقمي وتقنية المعلومات إلى 25%، مع بدء أعمال منهجيات واجهات البرمجة وإتاحة البيانات غير الشخصية لمختبر تجربة نسك ودراسة أدوات التحليل ومتطلبات الذكاء الاصطناعي.
- بلغ تقدم استراتيجية التقنية والتقنيات الناشئة والأتمتة لدى مركز منصة نسك 90%، وأدوات الاستماع الاجتماعي 80%، ومنهجيات تصميم الرحلات 75%.
- أبرز التحديات: استكمال منهجيات التنفيذ والتكامل وتوثيق الشواهد، وتسريع تنفيذ المتطلبات المشتركة قبل دورة التقييم.

خامسا: طلبات الدعم المرفوعة لمعاليكم

لم يتضمن التقرير طلبات دعم مستقلة مرفوعة لمعاليكم، فيما تبرز الحاجة إلى التوجيه بتسريع استجابة وكالة شؤون الحج، واعتماد حلول دمج المحتوى والنطاقات وملكية المحتوى، وحسم ترتيبات توحيد قنوات خدمة العملاء وتسريع إعداد كراسة مركز الاتصال، مع أهمية إحراز تقدم رسمي قبل نهاية ديسمبر لإدراجه ضمن الشواهد المعتمدة.

وتفضلوا بقبول خالص التحية والتقدير.
```

## Standard-model differences

For a `standard` report, change only these parts of the model:

- Introduction: «تجدون أدناه ملخص حالة المهام ومشاريع سهيل والمعاملات، وفق تقرير الإنجاز الأسبوعي المحدث بتاريخ <التاريخ>م.»
- Omit the whole «رابعا: مؤشر نضج التجربة الرقمية» section.
- The support section heading becomes «رابعا: طلبات الدعم المرفوعة لمعاليكم». If its table is empty, write «لم يتضمن التقرير طلبات دعم مرفوعة لمعاليكم.» without adding any digital-maturity needs.
